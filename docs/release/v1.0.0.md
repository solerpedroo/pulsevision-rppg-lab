## Limits and unfinished work

No authorized UBFC/PURE evaluation, positive face/ROI inspection or clinical
validation. No human accuracy, fairness or real sensor-to-screen latency claim.
No diagnosis, clinical ranges, SpO2 or facial identity. Live/offline paths have
bounded synthetic parity evidence, not general equivalence. Coverage and error
must be considered together; absent BPM/reference is legitimate.

A native retention test failed once with job failure during concurrent execution;
it passed alone and in the final full suite. The cause was not established and no
retry was added to hide it. Native worker stderr remains suppressed for privacy.
This merits monitoring if reproduced. See [state.md](../../state.md) for exact
results, scientific pending tasks and the complete implementation history.
